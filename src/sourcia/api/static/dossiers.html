Mes dossiers

Pour commencer

  1. Créez un dossier pour votre cours, juste au-dessus, ou essayez tout de suite avec un exemple.
  2. Ajoutez des sources du catalogue ou vos propres PDF. Elles sont cochées pour la suite.
  3. Préparez le contenu du cours (étape 3), puis produisez vos supports (étape 4).
