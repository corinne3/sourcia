# Exemples FICTIFS

Ces documents sont **inventés** pour tester SourcIA sans Internet : organismes génériques, lieux et chiffres imaginaires.
Chacun se termine par la mention « Document fictif ». Ils ne décrivent **aucun essai réel** et ne doivent jamais être cités comme sources.

- `documents/` : 8 documents (texte ; un saut de page = caractère `\f`)
- `catalogue.csv` : titre, source, caractère privé de chaque document
- `eval/` : un petit jeu de référence d'exemple (demandes + qualification « à la main »), pour tester l'évaluation
